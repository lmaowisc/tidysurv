# Tidy Survival Analysis

An applied guide to survival analysis and tidy reporting in R.

**Read online:** https://lmaowisc.github.io/tidysurv/

Open `tidysurv.Rproj` in RStudio and edit the `.qmd` manuscripts. See
[EDITING.md](EDITING.md) for dependencies, previewing, and publishing.

Chapters 1 and 2 contain worked narrative examples. Chapters 3–5 are under
construction; their original slides and code remain available. The materials
grow from the June 2025 short course.

GitHub Actions renders and publishes the website from `master`. The site is
built from source rather than from the historical `docs/` output directory.
